# Security Policy

## Supported Versions

Security fixes are applied to the latest state of the `main` branch.

| Version | Supported |
| --- | --- |
| `0.2.x` (`main`) | Yes |
| `< 0.2.0` | No |

## Reporting a Vulnerability

If you discover a security vulnerability in **fabnow** (such as XSS, SSRF in feed proxying, unsafe Service Worker caching, or credential leakage):

1. Please **do not** open a public issue with exploit details.
2. Open a private vulnerability report via GitHub Security Advisories on the repository, or contact the maintainer at `i@hyeona3.com`.
3. Include steps to reproduce, affected files/routes, and impact assessment.

We aim to acknowledge reports within 72 hours and coordinate a fix before public disclosure.
